## 2. Comprehensive Table Definitions

### 2.1. `collection_zones`
Municipal collection clusters dividing urban areas (Hyderabad demo zones).
- `id` (UUID, Primary Key, default `gen_random_uuid()`)
- `name` (TEXT NOT NULL) — e.g. "HITEC City & Madhapur"
- `code` (TEXT UNIQUE NOT NULL) — e.g. "ZONE-HYD-01"
- `center_lat` (DOUBLE PRECISION NOT NULL) — CHECK between -90 and 90
- `center_lng` (DOUBLE PRECISION NOT NULL) — CHECK between -180 and 180
- `radius_km` (DOUBLE PRECISION NOT NULL) — CHECK > 0
- `created_at` (TIMESTAMPTZ, default `now()`)

### 2.2. `collection_requests`
Citizen e-waste pickup requests with contact, address, slot, and status.
- `id` (UUID, Primary Key, default `gen_random_uuid()`)
- `citizen_name` (TEXT, Nullable for privacy)
- `citizen_phone` (TEXT, Nullable)
- `address` (TEXT NOT NULL)
- `zone_id` (UUID, FK -> `collection_zones.id` ON DELETE SET NULL)
- `lat` (DOUBLE PRECISION, Nullable, CHECK between -90 and 90)
- `lng` (DOUBLE PRECISION, Nullable, CHECK between -180 and 180)
- `pickup_date` (DATE)
- `pickup_slot` (TEXT) — e.g. "09:00 - 12:00", "14:00 - 17:00"
- `status` (TEXT NOT NULL DEFAULT 'pending') — CHECK:
  - `pending`
  - `scheduled`
  - `assigned`
  - `collected`
  - `weighed`
  - `sorted`
  - `sent_to_facility`
  - `recovered`
  - `cancelled`
- `priority` (TEXT NOT NULL DEFAULT 'normal') — CHECK: `low`, `normal`, `high`, `urgent`
- `notes` (TEXT, Nullable)
- `qr_token` (TEXT UNIQUE, Nullable) — Unique digital verification token
- `is_simulated` (BOOLEAN NOT NULL DEFAULT false) — Explicit flag separating simulated historical records from live user submissions
- `created_at` (TIMESTAMPTZ NOT NULL DEFAULT `now()`)
- `updated_at` (TIMESTAMPTZ NOT NULL DEFAULT `now()`)

### 2.3. Altered `items` Table (Zero Data Loss)
Existing 23 items retained intact; new column enables grouping items under a collection request:
- `request_id` (UUID NULL REFERENCES `collection_requests(id)` ON DELETE SET NULL)
- Index: `idx_items_request_id` ON `items(request_id)`

### 2.4. `vehicles`
Fleet units assigned to collection runs.
- `id` (UUID, Primary Key, default `gen_random_uuid()`)
- `vehicle_code` (TEXT UNIQUE NOT NULL) — e.g. "EV-VAN-01", "CNG-TRUCK-01"
- `capacity_kg` (NUMERIC NOT NULL) — CHECK > 0
- `vehicle_type` (TEXT NOT NULL) — CHECK: `EV_VAN`, `CNG_TRUCK`, `MINI_TRUCK`
- `status` (TEXT NOT NULL DEFAULT 'available') — CHECK: `available`, `assigned`, `in_route`, `maintenance`, `inactive`
- `depot_name` (TEXT, Nullable)
- `depot_lat` (DOUBLE PRECISION, Nullable) — CHECK between -90 and 90
- `depot_lng` (DOUBLE PRECISION, Nullable) — CHECK between -180 and 180
- `max_route_hours` (NUMERIC DEFAULT 8) — CHECK > 0
- `created_at` (TIMESTAMPTZ, default `now()`)

### 2.5. `collection_routes`
Optimized route itineraries generated by deterministic CVRP algorithm.
- `id` (UUID, Primary Key, default `gen_random_uuid()`)
- `vehicle_id` (UUID, FK -> `vehicles.id` ON DELETE SET NULL)
- `zone_id` (UUID, FK -> `collection_zones.id` ON DELETE SET NULL)
- `route_date` (DATE NOT NULL)
- `status` (TEXT NOT NULL DEFAULT 'planned') — CHECK: `planned`, `assigned`, `in_progress`, `completed`, `cancelled`
- `total_distance_km` (NUMERIC DEFAULT 0) — CHECK >= 0
- `total_load_kg` (NUMERIC DEFAULT 0) — CHECK >= 0
- `estimated_duration_minutes` (INTEGER DEFAULT 0) — CHECK >= 0
- `stops_json` (JSONB NOT NULL DEFAULT `'[]'::jsonb`) — Ordered sequence of stop requests with coords & order
- `created_at` (TIMESTAMPTZ NOT NULL DEFAULT `now()`)
- `updated_at` (TIMESTAMPTZ NOT NULL DEFAULT `now()`)

### 2.6. `collection_records`
Verification logs executed upon physical collection.
- `id` (UUID, Primary Key, default `gen_random_uuid()`)
- `request_id` (UUID NOT NULL, FK -> `collection_requests.id` ON DELETE CASCADE)
- `route_id` (UUID, FK -> `collection_routes.id` ON DELETE SET NULL)
- `collector_id` (UUID, Nullable until driver profile mapping)
- `actual_weight_kg` (NUMERIC NOT NULL) — CHECK > 0
- `verified_at` (TIMESTAMPTZ NOT NULL DEFAULT `now()`)
- `verification_method` (TEXT DEFAULT 'manual') — CHECK: `manual`, `qr_scan`, `digital_scale`
- `notes` (TEXT, Nullable)
- `created_at` (TIMESTAMPTZ, default `now()`)

### 2.7. `recovery_transfers`
Custodial transfers from collection vehicles to certified recycling/refurbishing facilities.
- `id` (UUID, Primary Key, default `gen_random_uuid()`)
- `facility_id` (UUID, FK -> `partners.id` ON DELETE SET NULL)
- `route_id` (UUID, FK -> `collection_routes.id` ON DELETE SET NULL)
- `total_weight_kg` (NUMERIC NOT NULL) — CHECK > 0
- `refurbished_pct` (NUMERIC NOT NULL DEFAULT 0) — CHECK between 0 and 100
- `recycled_pct` (NUMERIC NOT NULL DEFAULT 0) — CHECK between 0 and 100
- `residual_pct` (NUMERIC NOT NULL DEFAULT 0) — CHECK between 0 and 100
- Constraint: `(refurbished_pct + recycled_pct + residual_pct) <= 100`
- `transferred_at` (TIMESTAMPTZ NOT NULL DEFAULT `now()`)
- `notes` (TEXT, Nullable)

### 2.8. `event_log`
Immutable append-only audit trail capturing every system state transition.
- `id` (UUID, Primary Key, default `gen_random_uuid()`)
- `event_type` (TEXT NOT NULL) — e.g. `REQUEST_CREATED`, `PICKUP_ASSIGNED`, `ITEM_COLLECTED`, `SENT_TO_FACILITY`
- `entity_type` (TEXT NOT NULL) — e.g. `collection_requests`, `collection_routes`
- `entity_id` (UUID NOT NULL)
- `actor_role` (TEXT, Nullable) — e.g. `CITIZEN`, `DISPATCHER`, `COLLECTOR`
- `payload_json` (JSONB NOT NULL DEFAULT `'{}'::jsonb`)
- `created_at` (TIMESTAMPTZ NOT NULL DEFAULT `now()`)

### 2.9. `profiles`
User identity and role lookup extending Supabase `auth.users`.
- `id` (UUID, Primary Key, FK -> `auth.users(id)` ON DELETE CASCADE)
- `full_name` (TEXT, Nullable)
- `role` (TEXT NOT NULL DEFAULT 'CITIZEN') — CHECK: `CITIZEN`, `DISPATCHER`, `COLLECTOR`, `FACILITY`, `ADMIN`
- `created_at` (TIMESTAMPTZ, default `now()`)
